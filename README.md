# 📢 Channel Play Setup

</div>

### Step 1

Add **Rose X Music** to your Channel as Administrator.

### Step 2

Add **Rose X Music** to your Group as Administrator.

### Step 3

Run

```text
/channelplay
```

### Step 4

Select your Channel.

### Step 5

Done ✅

Now every song will stream directly into your **Channel Voice Chat**.
